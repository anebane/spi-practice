# ponytail 調査メモ（2026-09-08）

- 本体: https://github.com/DietrichGebert/ponytail （MIT / plugin v4.9.0）
- 正体: AIサービスではなく、**コーディングエージェント用のルールセット＋プラグイン**。
  Claude Code / Codex / Cursor / Copilot / Gemini CLI など多数のホストに同じ規則を配る形。
- 主張: 「一番良いコードは、書かなくて済んだコード」。書く前に7段のはしごを降り、最初に成り立つ段で止める。

## 中身（実際に読んだファイル）

`AGENTS.md`（2.5KB）と `skills/ponytail/SKILL.md` が本体。付随して
`ponytail-review`（差分の過剰実装レビュー）、`ponytail-audit`（リポジトリ全体版）、
`ponytail-debt`（`ponytail:` コメントの回収台帳）、`ponytail-gain`、`ponytail-help`。

はしご: 1 そもそも要るか(YAGNI) / 2 既にこのリポジトリにあるか / 3 標準ライブラリ /
4 プラットフォーム標準 / 5 既存の依存 / 6 1行で済むか / 7 ここで初めて最小実装。

## 測り方（ここが一番学べる）

- 実測: FastAPI+React の実リポジトリを headless Claude Code に12チケット編集させ、
  残った `git diff` で採点。n=4、Haiku 4.5。ベースライン比で **LOC -54% / トークン -22% /
  コスト -20% / 時間 -27% / 安全性 100%**。
- 対照群を2つ置いている（terse-prose の caveman、素の「YAGNI + one-liner」プロンプト）。
  caveman はトークン・コスト・時間が **増えた**。「短い散文」と「短いコード」は別物だと示している。
- 旧: 単発生成での「80-94%削減」は、issue #126 で「素のモデルは前置きで水増しするので不当」と
  指摘され、著者が **測り直して控えめな数字に差し替えた**。この訂正の作法自体が真似する価値あり。
- 注記も正直: 「トークン最小化が目的ではない」「はしごを熟考する推論モデル(GPT-5.5)では逆に増える」。

## 真似しなかったもの

- 多ホスト向けアダプタ（`.cursor/` `.windsurf/` `.qoder/` ほか十数種）と lifecycle hooks —
  単独開発・ホスト1つなので不要
- `lite/full/ultra` の強度切替 — 使う人が1人なら分岐が増えるだけ
- skill を6本に分ける構成 — 本人のはしご（ファイル数は少ないほう）に従い1本にまとめた
- ベンチマーク基盤（promptfoo 設定・SVG生成）— 効果測定が要るなら別途、この repo の test/ 側で測る

## 他プロジェクトで使う（2026-09-08 追記）

skill は**どのプロジェクトでも通る内容だけ**にしてある。プロジェクト固有の掟は書き写さず、
「そのリポジトリの `CLAUDE.md` / `AGENTS.md` を先に読む」に委ねている。
spi-practice の鉄則（`questions.js` を直接編集しない・変異を足す・問題数値を固定化しない・商標配慮）は
CLAUDE.md 側にそのまま残っているので、二重管理にならない。

全プロジェクトで有効にするには、`~/.claude/skills/` に置く。**コピーではなくリンク**にすると更新が1箇所で済む:

```
mkdir -p ~/.claude/skills
ln -s ~/Documents/spi-practice/.claude/skills/lean ~/.claude/skills/lean
```

リンクが効かない場合は `cp -r ~/Documents/spi-practice/.claude/skills/lean ~/.claude/skills/` でも良いが、
その場合は spi-practice 側を直したときに手で反映し直す必要がある。
どちらの場合も Claude Code を起動し直してから `/lean` が見えることを確認する。

⚠️ spi-practice ではプロジェクト側 (`.claude/skills/lean`) と個人側 (`~/.claude/skills/lean`) の
**名前が衝突する**。リンクなら実体が同じなのでどちらが勝っても同じ内容が読まれる。コピーだと食い違い得る。
