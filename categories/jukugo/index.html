熟語の成り立ちの解き方

分野別の解き方 ＞ 熟語の成り立ち

熟語の成り立ちは、知識ではなく手順で解けます。二字を1字ずつ訓読みして、短い文にする。これだけで5つの型のどれかに必ず落ちます。

目次

  2. 5つの型
  3. 例題：成り立ちを選ぶ
  4. 例題：同じ成り立ちの熟語を選ぶ
  5. 1字違いで型が変わる
  6. 迷ったときに試す順番
  7. つまずきやすい点

1. まず「読み下す」

この分野で唯一やることは、熟語を短い文に開くことです。

「読書」なら「書を読む」。「日没」なら「日が没する」。「急流」なら「急な流れ」。文にした時点で、型はもう決まっています。逆に、文にできないまま選択肢を眺めていると、いつまでも決まりません。

熟語を見た瞬間に意味で判断せず、2字を分解して訓読みする。それが最初の一手です。

2. 5つの型

  • 似た意味の漢字を重ねる：2字が同じような意味（温暖＝温かい・暖かい）
  • 反対の意味の漢字を重ねる：2字の意味が逆（増減＝増える ⇄ 減る）
  • 主語と述語の関係：前が「〜が」、後ろが「どうする」（日没＝日が没する）
  • 動詞の後に目的語をおく：後ろから前へ読む（読書＝書を読む）
  • 前の漢字が後ろの漢字を修飾する：前から後ろへ読む（急流＝急な流れ）

出題はこの5つのどれかです。ポイントは読む向きで、目的語型は後ろから前へ、修飾型は前から後ろへ読みます。

3. 例題：成り立ちを選ぶ

次の熟語の成り立ち方として当てはまるものを選べ。
骨折
ア 似た意味の漢字を重ねる　イ 反対の意味の漢字を重ねる　ウ 主語と述語の関係　エ 動詞の後に目的語をおく

解き方

  • 2字を訓読みする → 「骨」「折れる」
  • 文にする → 「骨が折れる」
  • 「〜が〜する」の形になった → 主語と述語。正解はウ

ここで「骨を折る」と読んでしまうとエになります。実際に折れているのは骨のほうなので、骨は主語です。迷ったら「誰が・何が」を探してください。

4. 例題：同じ成り立ちの熟語を選ぶ

次の成り立ち方をしている熟語を選べ。
前の漢字が後ろの漢字を修飾する
ア 救助　イ 洗顔　ウ 濃霧　エ 進退

解き方

  • ア 救助 → 「救う・助ける」。似た意味
  • イ 洗顔 → 「顔を洗う」。目的語型
  • ウ 濃霧 → 「濃い霧」。修飾型。これが正解
  • エ 進退 → 「進む ⇄ 退く」。反対

4つ全部を読み下してから決めます。1つ目が合っていそうでも最後まで確かめるほうが、結果的に速く終わります。

5. 1字違いで型が変わる

この分野でいちばん間違えるのが、字面が似ている熟語です。

  • 増加＝増す・加わる → 似た意味／増減＝増える ⇄ 減る → 反対
  • 寒冷＝寒い・冷たい → 似た意味／寒暖＝寒い ⇄ 暖かい → 反対
  • 巨大＝巨きい・大きい → 似た意味／巨木＝巨大な木 → 修飾
  • 大小＝大きい ⇄ 小さい → 反対／大木＝大きい木 → 修飾

いずれも1字しか違いません。熟語ごと丸暗記すると、この対で必ず崩れます。毎回読み下す習慣をつけてください。

6. 迷ったときに試す順番

型が思い浮かばないときは、次の順で当てはめると早く決まります。

  • まず2字の意味が近いか逆かを見る（ここで決まるものが最も多い）
  • 決まらなければ後ろから前へ「〜を〜する」と読んでみる
  • それも違えば前から後ろへ「〜な〜」と読んでみる
  • 残ったら「〜が〜する」。主語と述語

近い・逆の判定がいちばん速いので先に済ませます。読む向きを変える2手で、ほとんどの熟語が決まります。

7. つまずきやすい点

音読みのまま考えてしまう

「コッセツ」と読んでいる限り、型は見えません。訓読みに開くことが前提の作業です。

目的語型と主述型の取り違え

「骨折」「気絶」は、前の字が主語です。「洗顔」「点火」は、後ろの字が目的語です。動作しているのがどちらの字かで分かれます。

熟語を覚えようとする

出題される熟語は無数にあります。覚えるのは5つの型と読み下しの手順だけで十分です。

熟語の成り立ちだけを練習する

問題は毎回自動生成されるので、同じ問題が再び出ることはほとんどありません。登録不要・無料。
