語句の関係の解き方

分野別の解き方 ＞ 語句の関係

語句の関係は、感覚で選ぶと外れます。示された二語の関係を口に出せる一文にする。この一手だけで正答率が変わります。

1. 関係を「言葉にする」

語句の関係は、感覚で選ぶと必ず外れます。手順は1つ、示された二語の関係を、口に出せる一文にすることです。

「AはBの一種」「AはBの材料」「AとBは反対」——このように言い切れる形にしてから、選択肢を同じ文に当てはめます。言葉にできない関係を選んでいるうちは、正答率は上がりません。

2. よく出る関係の型

  • 包含：AはBの一種（トンボは昆虫の一種）
  • 材料：BはAの原料（サトウキビは砂糖の原料）
  • 部分：BはAの一部（弦はギターの一部）
  • 用途：AはBのために使う（調律師はピアノを調律する）
  • 対義：AとBは反対（建設と破壊）
  • 役割：AがBを行う（医師と診察）

実際の出題は、この6つのどれかであることがほとんどです。型を先に見分けてから選択肢を見ると、迷いが消えます。

3. 例題：同じ関係を選ぶ

最初に示した二語の関係を考え、同じ関係になっている組み合わせを選べ。
建設 : 破壊
ア 調律師 : ピアノ　イ 昆虫 : トンボ　ウ ギター : 弦　エ 需要 : 供給

解き方

  • 「建設 : 破壊」を言葉にする → 反対の意味
  • ア 調律師とピアノ → 用途。反対ではない
  • イ 昆虫とトンボ → 包含（トンボは昆虫の一種）
  • ウ ギターと弦 → 部分
  • エ 需要と供給 → 反対。これが正解

4つを順に言葉にするだけで決まります。「なんとなく近い」で選ばないことが、この分野の唯一のコツです。

4. 例題：仲間はずれを選ぶ

次の4つのうち、二語の関係が他の3つと異なるものはどれか。
ア 砂糖 : サトウキビ　イ アルミニウム : ボーキサイト　ウ 鉛筆 : 芯　エ 紙 : パルプ

解き方

  • ア 砂糖とサトウキビ → 材料
  • イ アルミニウムとボーキサイト → 材料
  • ウ 鉛筆と芯 → 部分（芯は鉛筆の一部であって、原料ではない）
  • エ 紙とパルプ → 材料

正解はウ。「材料」と「部分」は混同しやすい型です。原料は加工されて元の形を失いますが、部分はそのまま含まれています。芯は鉛筆の中にそのままあるので部分です。

5. 語順にも注意する

「昆虫 : トンボ」と「トンボ : 昆虫」は、関係の向きが逆です。前者は「大きい分類 : 具体例」、後者は「具体例 : 大きい分類」。

選択肢が向きだけ違う形で並んでいることがあります。言葉にするときは、必ずAを主語にして文を作ると、向きの取り違えを防げます。

6. 迷ったときの絞り方

型を言葉にしても2つ残ることがあります。そのときは、より具体的に言い直すと決まります。

  • 「関係がある」では絞れない → 「AがBを作る」まで言い切る
  • それでも残る → 語順を入れ替えて成立するか試す
  • 「BはAの一種」が成立するのは包含だけ、という具合に型ごとの言い回しで判定する

たとえば「医師 : 診察」と「画家 : 絵画」。前者は行為（医師が診察を行う）、後者は成果物（画家が絵画を作る）です。どちらも「AがBをする」に見えますが、Bが動作か物かで型が分かれます。

この一段の言い直しで、ほとんどの二択は解けます。

7. つまずきやすい点

意味の近さで選んでしまう

「パンと小麦」と「パンとバター」は、どちらもパンに関係しますが、前者は材料、後者はただの連想です。関係の型が一致しているかだけを見てください。

材料と部分の混同

加工されて姿が変わるなら材料、そのまま含まれているなら部分。この線引きで判定できます。

時間をかけすぎる

1問60秒の分野です。型に当てはまらないと感じたら、いったん飛ばして次に進むほうが総得点は上がります。
