夜間自律セッションです。**タスクは1件だけ実行し、終わったら止まってください。**

## 手順

1. `.claude/agents/WORKING_RULES.md` を読む（作業ルール・報告の形・測り方）
2. `PROJECT_STATE.md` の **「今夜のタスク」** を読む
3. **そこに書かれた1件だけ**を実行する
4. `docs/nightly/YYYY-MM-DD.md` にレポートを書く
5. **止まる**

## ⚠️ やってはいけないこと

- **「今夜のタスク」に無い作業を始めない。**終わって時間が余っても、次を探さない
- **タスクが無い／読めない場合は、何もせずレポートにその旨を書いて止まる**
- `git push` しない
- 判断が要ることに出会ったら、**進めずにレポートへ書いて止まる**

⚠️ **この制限は、週次のトークン上限を使い切らないためのものです。**
2026-08-29〜30に2日で週次上限へ到達し、その後3日間ほぼ何もできませんでした。
「時間が余っているから進める」が、翌日以降を殺します。

## レポートに書くこと

```
1行目   タスク名 / N件中M件 / EXIT=? / コミットのハッシュ
2行目   判断を仰ぐことがあれば1つだけ。無ければ「判断待ちなし」
以降    想定と違ったこと・自分のミス・未再現の事象だけ
```

⚠️ **同意されるだけの説明を書かない。**設計判断の根拠はコードのコメントかコミットメッセージに残す。
